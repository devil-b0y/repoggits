# CampusFlow — working sample source

A fictional student project for the Repoggits example listing. Open `index.html` in a modern browser. No installation, account, API keys, or build step is required.

## Try it

1. Add a task with a subject, teammate, priority, and due date.
2. Start it, mark it complete, and watch the progress totals update.
3. Search by task, subject, or teammate.
4. Reload to check browser-local persistence. Reset demo restores the six sample tasks.

## Files

- `index.html`: semantic page, task board, and accessible native task dialog.
- `styles.css`: responsive layout, styles, and reduced-motion support.
- `app.js`: task state, safe DOM rendering, search, and localStorage persistence.

This is a browser-local prototype, not a multi-user service. The fictional team names, colleges, project dates, and illustrative cost estimates in the listing demonstrate the repository fields. Portraits in the listing are AI-generated; screenshots and video show this actual demo. All code in this ZIP is readable source; it contains no generated media, credentials, dependencies, or executable binaries.

The displayed hardware cost is INR 0. Estimated optional deployment costs are INR 650 for a domain and INR 150 for a month of hosting; neither is required to run this offline demo and these are illustrative amounts, not provider quotations.
